# Result Files

Upon completion, the pipeline cleans up temporary files and saves the primary analysis deliverables under the `Results/` directory.

The table below outlines the structure and description of these files, where `{sample}` is replaced by the sample/patient ID and `{type}` is replaced by the sample type (typically `T` for Tumor).

---

## Primary Output Files

| Directory / File Path | File Type | Description |
|-----------------------|-----------|-------------|
| **Alignment** | | |
| `Results/Data/{sample}_{type}.ont_reads.filtered.aligned.sorted.soft-clipped.bam` | BAM | Aligned reads, sorted and soft-clipped of primer regions. Used for downstream validation. |
| `Results/Data/{sample}_{type}.ont_reads.filtered.aligned.sorted.soft-clipped.bam.bai` | BAI | Index file for the aligned BAM file. |
| **Reads** | | |
| `Results/Data/{sample}_{type}.ont_reads.filtered.fastq.gz` | FASTQ | Unaligned, quality-filtered and length-filtered reads from Filtlong. |
| **Variant Calls** | | |
| `Results/Data/{sample}_{type}.ont_reads.snv-indels.vcf` | VCF | Ensembled and annotated SNV/Indel calls from ClairS-TO, DeepSomatic, and VarDict. |
| `Results/Data/{sample}_{type}.ont_reads.cnv-sv.vcf.gz` | VCF | Structural variant calling outputs generated by Sniffles2. |
| **Reports** | | |
| `Results/Reports/{sample}_{type}.xlsx` | XLSX | Comprehensive Excel report containing quality metrics, coverage statistics, yield, and prefiltered variant calls. |
| `Results/Reports/multiqc_report.html` | HTML | Interactive MultiQC dashboard detailing run stats, Picard metrics, and Sequali summaries. |

---

## Design and Support Files

Additionally, several design BED files and temporary tables are kept in the output directory for auditability and troubleshooting purposes.

| Directory / File Path | File Type | Description |
|-----------------------|-----------|-------------|
| `Results/Bed/` | Directory | Copy of the target, primer, and overlapping region BED files used for alignment clipping and coverage calculations. |
| `Results/Reports/{sample}_{type}.*.csv` | CSV | Support tables containing raw data exported into the final Excel sheet. |
| `Results/Reports/timestep_coverage_per_amplicon/` | Directory | Yield and coverage plots displaying target amplification trends over time. |
| `Results/Reports/D25-test007_T_config.yaml` | YAML | Archive of the configuration settings used during this pipeline run. |
| `Results/Reports/D25-test007_T_resources.yaml` | YAML | Archive of the compute resources requested for the job execution. |
